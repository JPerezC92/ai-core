## Specs

- S1 — TypeScript y JavaScript se indentan con tabuladores reales, visualizados a 4 columnas. Exact requirement: "Quiero adoptar tabs reales para TypeScript y JavaScript, con un ancho visual predeterminado de 4 espacios. Esto significa que cada nivel de indentación debe utilizar un carácter de tabulación, no cuatro espacios físicos." Acceptance: inspeccionar los bytes de un archivo `.ts` formateado y observar que cada nivel de indentación es exactamente un byte `0x09` y que el ancho visual configurado es 4.
- S2 — JSON, JSONC, YAML y Markdown conservan indentación con espacios en el ancho convencional de cada formato. Exact requirement: "Para JSON, JSONC, YAML y Markdown, utiliza espacios y convenciones apropiadas para cada formato." Acceptance: inspeccionar un `.json`, un `.jsonc`, un `.yaml` y un `.md` formateados y observar solo caracteres de espacio en la indentación, a 2 por nivel en JSON/JSONC/YAML.
- S3 — Los archivos se codifican en UTF-8 con LF y newline final, y Markdown conserva espacios finales. Exact requirement: "Mantén UTF-8, LF, newline final y la excepción de `trim_trailing_whitespace = false` para Markdown, ya que pueden existir espacios finales significativos." Acceptance: inspeccionar el EditorConfig final y una línea Markdown terminada en dos espacios, y observar que las cuatro reglas están declaradas y que los espacios finales sobreviven al formateo.
- S4 — EditorConfig y Biome declaran el mismo valor para cada ajuste que ambos controlan. Exact requirement: "Configura Biome y EditorConfig coherentemente, utilizando las opciones específicas por lenguaje cuando sea necesario. Evita configuraciones contradictorias." Acceptance: comparar ajuste por ajuste ambos archivos y observar que cada valor solapado coincide en estilo de indentación, ancho, fin de línea y ancho de línea.
- S5 — Biome formatea todo lenguaje compatible presente en el repositorio, incluida la documentación. Exact requirement: "Quiero aprovechar la capacidad de Biome para formatear distintos lenguajes, no limitarlo a TypeScript. ... - S6 — El Markdown formateado conserva significado, estructura y los contratos que consumen los agentes. Exact requirement: "No quiero que el formatter rompa documentación estructurada que utilizan mis agentes."
