## Upstream reference baseline

The October 28 source assessment identified `main` at **`a6e371b502a24a0a0f57e8d75730150416c0d3f3`**. Its [usage guidance][upstream-usage], [intended usage][upstream-intended] and [routing renderer][upstream-routing] were reported byte-identical to the inspected v4.3.1 target `2dba7784114fff57864519c4c0d067e952a8c98b` (governing feature L13). Both usage pages explicitly say they track `main` and link to v4.0.0 docs; a pinned file is not therefore release-specific documentation. The earlier v4.2.0 evidence remains dated research, not a substitute baseline.

The current documented order is **short header → Specs → Tasks → Log**, not the old Objective/Problem/Scope layout. Public prose specifies a short header; the renderer further names objective, branch, delivery strategy and test runner as header content. Specs preserve the user's exact strings, error messages and examples verbatim, alongside acceptance checks; L1 preserves the original request verbatim. The [October 3 transition](https://github.com/Gentleman-Programming/gentle-ai/commit/6c6649159cfe7b590acffa9b9600db2d10e403b5) explains older examples, not a second current schema. See chapters [06](../research/agent-workflows/odd-gentleman-programming/06-feature-document-blueprint.md) and [07](../research/agent-workflows/odd-gentleman-programming/07-upstream-local-alignment.md) for evidence layers and limits.

Upstream distinguishes the advisory **about-400-line task heuristic** from its **delivery forecast/running count**: the latter counts authored additions plus deletions, excludes generated files, and applies the chosen delivery strategy. Neither is a file-count classification rule or permission to force cosmetic splits. Conditional deterministic test-first, observed task checks, coherent work-unit commits and proportional delegation are part of the source guidance; their presence in prose does not prove model behavior. Pi/Gentle Shell has separately owned ODD prompt delivery and Pi-specific steps; runtime parity remains unverified.
