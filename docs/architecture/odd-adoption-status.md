## Three evidence states

Every alignment claim below separates three states, and no row converts one into another.

- **Documented alignment** — prose at the named local owner covers the stated concept. It is a reading of that file at this revision: not technical enforcement and not agent behavior.
- **Observed execution** — a scenario actually ran, and the row names the recorded evidence. Where the only record is the governing feature's own Log, the row says so; nothing is upgraded to observed without it.
- **Unverified** — the inspected evidence does not settle the point. A validator exit 0, an anatomy pass, a reviewer verdict or a ticked checklist item upgrades nothing here: those establish document mechanics or review scope, never runtime behavior, conformance or adoption.
