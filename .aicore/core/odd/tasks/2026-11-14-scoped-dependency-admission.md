- S2 — The package-manager outdated check is optional maintenance information and never a mandatory security-approval step. - L4 — 2026-11-14 — Permission semantics verified from the OpenCode V2 documentation before the permission design was fixed, not from the prior proposal. Whole-value wildcard matching over the raw command string (`*` matches zero or more characters including `/`; a pattern ending in ` *` also matches the command without arguments); rules combine in order and the last match wins; lower-priority configuration loads first, global rules next, agent rules last, so an agent block overrides a global rule; the `shell` resource is the scanner-produced command string and every extracted subcommand and `cd` target is checked; a configured `deny` is never overridden by a saved approval. Consequence for the withdrawn proposal: a prefix pattern such as `pnpm install*` does not match `pnpm --dir <path> install`, `pnpm i`, or `pnpm  install`, and it never matches an invocation through another executable,
  so it could not carry the boundary it claimed. The eight global pnpm denies are withdrawn; the correction is scoped to Forge's agent block.
